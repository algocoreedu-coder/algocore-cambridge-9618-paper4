# B4 A1 learning handoff

Batch B4 supplies the bilingual, trace-backed handoff for algorithm rewrite, binary-tree setup, insertion, search and traversal.

Every fixture has a stable pattern, variant, entry-point binding, source authority label, typed initial/final snapshot, invariant assertions and VI–EN event explanation. Recursive boundaries are represented explicitly: the null-subtree guard comes before the recursive call; child direction and the duplicate-key policy are visible in each event; and traversal order is derived from topology rather than storage order.

The source fixture rows retain the exact QP/MS part identifiers from the frozen Stage 4 inventory. Any adaptation is labelled `AlgoCore_test_policy`; the implementation never claims to reproduce an official source literal. The event bundle uses every frozen B4 visual event ID and covers normal, boundary and failure scenarios with run-backed traces.
