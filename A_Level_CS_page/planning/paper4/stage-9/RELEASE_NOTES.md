# Stage 9 release notes — paper4-2026-s9-v1

Stage 9 turns the released Paper 4 corpus and Stage 8 visual runtime into a bilingual learning course in Fumadocs.

- 13 packages, 26 lessons and 260 canonical learning blocks.
- 58 exact visual-pattern joins across 20 runtime lessons; 6 lessons use explicit static academic support.
- Complete worked examples, practice progression, hidden-answer retrieval and mark-protection chains for all 26 lessons.
- VI/EN content and interface labels, including nested rubrics, hints, feedback and source cards.
- Source resolver that never exposes local locators as deployed hrefs; 138/138 unique locators resolve.
- Responsive 320 px layout, dark theme, reduced motion, keyboard focus and locale/state preservation.
- Deterministic registry and pedagogy verification, TypeScript and production build in `npm run verify:stage9`.

The release remains a local learning application. Accounts, automated grading, learner progress persistence and public deployment are outside this stage.
