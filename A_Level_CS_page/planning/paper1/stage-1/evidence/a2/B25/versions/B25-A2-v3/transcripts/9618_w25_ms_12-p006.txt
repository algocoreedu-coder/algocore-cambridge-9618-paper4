4(c) 
1 mark per bullet point, max 4 marks 
 
• 
SELECT COUNT statement 
• 
Using the correct tables 
• 
Joining the tables 
• 
The condition for the name 
 
Example Answer 1: 
 
SELECT COUNT(ContainerID) 
FROM CONTAINER, SHIP 
WHERE CONTAINER.ShipID = SHIP.ShipID 
AND ShipName = "Caledonia"; 
 
Example Answer 2: 
 
SELECT COUNT(ContainerID) 
FROM CONTAINER INNER JOIN SHIP 
ON CONTAINER.ShipID = SHIP.ShipID 
WHERE ShipName = "Caledonia";
