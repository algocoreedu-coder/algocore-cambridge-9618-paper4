Monitoring systems do not take any action whereas control systems act 
autonomously to change the environment if the values are out of a 
prescribed range 
• 
Control systems use actuators monitoring systems do not have any 
actuators 
• 
Control systems make use of feedback monitoring systems do not make 
use of feedback 
• 
The output from a monitoring system does not affect the subsequent 
input whereas output from a control system affects the next input.
