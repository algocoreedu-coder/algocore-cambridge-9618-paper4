5(d)(i) 
1 mark for each point 
 
• 
Select COUNT 
• 
FROM (using correct tables) and joining 
• 
WHERE (or AND) condition for correct username 
 
Example 1: 
SELECT COUNT(ItemName) 
FROM CHARACTER_ITEM INNER JOIN CHARACTER  
ON CHARACTER.CharacterID = CHARACTER_ITEM.CharacterID 
WHERE CHARACTER.Username = "KAT123"; 
 
Example 2: 
SELECT COUNT(ItemName) 
FROM CHARACTER_ITEM, CHARACTER  
WHERE CHARACTER.CharacterID = CHARACTER_ITEM.CharacterID 
AND CHARACTER.Username = "KAT123";
