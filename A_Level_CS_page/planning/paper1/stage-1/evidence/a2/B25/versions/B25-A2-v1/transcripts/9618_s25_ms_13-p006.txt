A compiler checks all of the code before attempting to translate the program. 
If any errors are found, they are all reported at the same time and the program 
does not translate or run. If there are no errors found, the compiler produces 
an executable file/.exe which can run without access to the source/program 
code. 
 
An interpreter translates one line of code and then runs it, before moving to 
the next line of code. If the line of code has an error, the interpreter stops and 
displays the error. The programmer can correct the error immediately/in real-
time and then the interpreter continues translating from that point.
