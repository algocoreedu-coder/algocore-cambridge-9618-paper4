Term 
Description 
Entity 
An object that data is stored about. 
Tuple 
A row of data in a table about one 
instance of an object. 
Secondary key 
An additional/alternative key used as well 
as the primary key to locate specific data 
// a candidate key that has not been 
chosen as a primary key. 
Foreign key 
A field in one table that is linked to a primary 
key in another table.
