## Trạng thái

Đã có cấu trúc, khung kế hoạch và kiểm kê đề theo tên file. Chưa phân tích từng câu trong toàn bộ kho đề,
chưa có giáo án từng buổi, website hay repository GitHub mới. Không có thao tác deploy trong bước chuẩn bị này.

Các tham số đang chờ: ngày bắt đầu, năm/kỳ thi AS và A Level, số buổi/tuần, thời lượng buổi,
trình độ đầu vào, ngôn ngữ lập trình và ngôn ngữ giảng dạy. Bản khung chưa khóa theo lịch thi cụ thể.
